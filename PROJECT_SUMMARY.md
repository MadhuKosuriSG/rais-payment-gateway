## 🗄️ Database Schema

### 4 Core Tables

1. **`payments`** - Logical payment intent
   - Stores: amount, status, public_reference, idempotency_key
   - Purpose: One record per user payment action

2. **`payment_attempts`** - Razorpay order attempts
   - Stores: razorpay_order_id, attempt_number, status
   - Purpose: Track retries (one payment can have multiple attempts)

3. **`gateway_transactions`** - Actual Razorpay payments
   - Stores: razorpay_payment_id, method, fees, card details
   - Purpose: Map Razorpay payment to our system

4. **`webhook_events`** - All incoming webhooks
   - Stores: event_id, payload, processed status
   - Purpose: Idempotent webhook processing, audit trail

### Key Relationships

```
Payment (1) ──< (many) PaymentAttempt ──< (many) GatewayTransaction
                                              ↑
                                              │
                                        WebhookEvent
```

## 🔌 API Endpoints

### 1. Create Payment
```
POST /payments
```
**Purpose:** Create payment record with idempotency key

### 2. Create Razorpay Order
```
POST /payments/:id/create_order
```
**Purpose:** Generate Razorpay order for checkout

### 3. Get Payment Status
```
GET /payments/:id
```
**Purpose:** Check payment status (for frontend polling)

### 4. Webhook Receiver
```
POST /webhooks/razorpay
```
**Purpose:** Receive payment status updates from Razorpay

## 💳 Payment Flow

```
1. Frontend → POST /payments (idempotency_key + amount)
   ↓
2. Backend creates Payment (status: created)
   ↓
3. Frontend → POST /payments/:id/create_order
   ↓
4. Backend creates Razorpay order (status: initiated)
   ↓
5. Frontend opens Razorpay Checkout
   ↓
6. User completes payment
   ↓
7. Razorpay → POST /webhooks/razorpay (payment.captured)
   ↓
8. Backend updates status (status: captured)
   ↓
9. Frontend polls GET /payments/:id
   ↓
10. Shows success message
```

## 🛡️ Security Features

### 1. Webhook Signature Verification
- HMAC SHA256 signature validation
- Prevents fake webhook attacks

### 2. Idempotency
- `idempotency_key` prevents duplicate payments
- `event_id` prevents duplicate webhook processing
- Database unique constraints enforce at DB level

### 3. No Sensitive Data
- Never stores CVV, full card numbers, OTP
- Only stores last 4 digits for display
- PCI DSS compliant

### 4. CORS Configuration
- Restricted origins for payment APIs
- Open for webhooks (Razorpay servers)

## 📊 State Management

### Payment States
```
created → initiated → pending → captured ✓
                              → failed ✗
                              → cancelled ✗
```

### When Each State Occurs

- **created**: Payment record created
- **initiated**: Razorpay order created
- **pending**: User opened checkout (optional)
- **captured**: Money received (webhook)
- **failed**: Payment failed (webhook)
- **cancelled**: User cancelled

## 📈 Monitoring Metrics

### Key Metrics to Track

1. **Payment Success Rate**
   - Target: > 85%
   - Alert if: < 80%

2. **Webhook Processing Time**
   - Target: < 1 second
   - Alert if: > 5 seconds

3. **Unprocessed Webhooks**
   - Target: 0
   - Alert if: > 10

4. **Failed Payments**
   - Monitor daily
   - Investigate spikes

### Database Queries for Monitoring

```sql
-- Success rate (last 24 hours)
SELECT 
  COUNT(*) as total,
  SUM(CASE WHEN status = 'captured' THEN 1 ELSE 0 END) as successful,
  ROUND(SUM(CASE WHEN status = 'captured' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as rate
FROM payments
WHERE created_at > NOW() - INTERVAL 24 HOUR;

-- Unprocessed webhooks
SELECT COUNT(*) FROM webhook_events WHERE processed = FALSE;

-- Failed payments today
SELECT COUNT(*) FROM payments 
WHERE status = 'failed' 
AND DATE(created_at) = CURDATE();
```

## 🤝 Support & Maintenance

### Common Tasks

**Check payment status:**
```bash
rails console
> Payment.find_by(public_reference: 'PAY_ABC123')
```

**Reprocess failed webhook:**
```bash
rails console
> webhook = WebhookEvent.find(123)
> Webhooks::ProcessService.new(
    event_id: webhook.event_id,
    event_type: webhook.event_type,
    payload: webhook.payload,
    signature: webhook.signature
  ).call
```

**Check unprocessed webhooks:**
```bash
rails console
> WebhookEvent.unprocessed.each do |webhook|
    puts "#{webhook.event_id} - #{webhook.event_type} - #{webhook.created_at}"
  end
```
